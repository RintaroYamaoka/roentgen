## data/*.json の形(差分を取るための正本)

```
data/
  meta.json        repo, sha, date, langs[], products[]
  infra.json       framework, hosting, db{kind,source:"migration"|"live"}, env_keys[], crons[], saas[]
  schema.json      tables[{name,columns[{name,type,nullable}],fks[],rls,first_migration,last_migration,rows?}], migrations[], drift?{only_live[],only_migration[]}
  entries.json     entries[{kind,path,file,auth:"middleware"|"inline"|"none"|"unknown",tested}]
  deps.json        layers[{path,files,lines}], edges[{from,to,count}], rules[{from,to,kind,count,files[]}], cycles[]
  modules.json     modules[{path,layer,exports[{name,kind}],imported_by,imports_layers[]}]
  symbols.json     symbols[{name,kind,file,layer,extends[],implements[],refs[]}]   ← kind: class|interface|type|enum|struct|trait|protocol|fn
  churn.json       files[{path,count,lines,authors[]}], prs[], weekly[]
  risks.json       items[{rank,kind,path,why,links[]}]      ← LLM が書くが根拠 path は機械の値に限る
  dev.json         scripts{}, ci[], conventions{}, tests{count,framework,layers}
  glossary.json    terms[{ja,code,source}]
  narrative.json   {"00":[...3行...], "01":..., "09":...}
  unknown.json     items[{what,why,how_to_fix}]
```

差分は `schema / entries / deps / modules / symbols / churn(耐力壁) / infra` の 7 本を前回と突き合わせる。`narrative` と `risks` は比較しない(LLM の揺れを差分に見せない)。
